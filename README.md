# Workshop Gen AI

This repository contains multiple coding challenges for the workshop.

## Challenge Structure

Each challenge has its own initial code structure, which can be found in its respective branch. For example:
- The **flocking challenge** starting code is in the `flocking` branch.
- The **shared expense challenge** starting code is in the `shared_expense` branch.

To get started with a challenge, checkout the relevant branch:

```bash
git checkout <branch-name>
```

Replace `<branch-name>` with the branch for your chosen challenge.

## Main Branch

The main branch contains documentation and instructions, but not the runnable code for each challenge.

## How to Participate

I would suggest copying the file for the challenge you want into a separate doc that is not available to the agent.
Feel free to do what you want moving forward from that.

1. Choose a challenge.
2. Checkout its branch.
3. Follow the instructions in the challenge markdown file.

---

For more information, see the markdown files in the repository and the instructions in each branch.
