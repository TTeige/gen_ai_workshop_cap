# Shared Expense Splitter

Build a small full-stack app for tracking shared expenses in a group. Think "Oppgjør" in Vipps.

## Goal

Create a runnable app where users can add participants, add expenses, and see who owes what.

## Requirements

Your app should:

- run locally
- let users add participants
- let users add expenses
- let users choose who paid
- let users choose who shares an expense
- calculate and show current balances

## Notes

Keep it small. A simple working version is better than an ambitious incomplete one.

The backend logic is the main focus. The UI can be simple.

Use in-memory data unless you already have something else ready.

## Good starting points

A typical approach could be:

1. define the data model
2. create simple backend endpoints
3. add a small UI for participants and expenses
4. calculate balances
5. show the result clearly

## Optional ideas

If the basics work, you can add things like:

- equal vs custom split
- edit or delete expense
- settlement suggestions
- categories
- validation and error handling
